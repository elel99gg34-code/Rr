## 간단한 Python 챗봇

이 프로젝트는 Python으로 만든 간단한 콘솔 기반 챗봇입니다.

### 콘솔 챗봇 실행 방법

1. Python이 설치되어 있는지 확인하세요.
2. 터미널에서 다음 명령을 실행하세요:
   ```
   python chatbot.py
   ```
3. 챗봇과 대화를 시작하세요. 'exit'를 입력하면 종료됩니다.

### 웹 챗봇 실행 방법 (Flask)

1. Python과 pip가 설치되어 있는지 확인하세요.
2. Flask 설치:
   ```
   pip install flask
   ```
3. 서버 실행:
   ```
   python app.py
   ```
4. 브라우저에서 아래 링크 클릭 또는 주소로 접속
   - http://localhost:5000
   - http://127.0.0.1:5000

### 공개 주소(인터넷에서 접근 가능)

- GitHub Codespaces 사용 중이면 포트 포워딩 후 제공되는 URL을 사용합니다.
- ngrok 설치 후:
  ```bash
  ngrok http 5000
  ```
  생성된 공개 URL(예: https://abcd1234.ngrok.io)을 브라우저에서 엽니다.
- 로컬터널 사용:
  ```bash
  npm install -g localtunnel
  lt --port 5000
  ```

### 기능

- 콘솔/웹 인터페이스 모두 지원
- 랜덤 응답 생성
- '기분', '어때' 키워드에 대한 특별 응답
- 운세: 1~100 랜덤 점수
- 추천: 음식, 주스, 디저트, 커피, 차, 샐러드 등 카테고리별 랜덤 추천 (5개씩)
- 시간: 현재 시각 응답
- 스포츠 근황: 축구, 야구, 농구, 프리미어 리그, 배구, 배드민턴, 탁구 정보 제공
- 칭찬 반응: "귀여워!", "멋지다!" 등 칭찬 + "!" 입력 시 감사 응답
- 고민 위로: "고민있어", "힘들어" 등 고민 키워드 입력 시 위로 메시지
- 자기소개: "너는 누구야?", "너 누구야" 등 질문 시 챗봇 소개
- 밸런스 게임: "A가 좋아 B가 좋아", "A vs B", "A 아니면 B" 형식으로 두 옵션 중 랜덤 선택
